# Mission props 0.7.0

Bảy PNG RGBA hoàn thiện được tạo bằng built-in ImageGen, transparent_background=true. PNG gốc giữ nguyên ở ../../Assets/IonFrontier/Art/MissionProps. Receipts lưu prompt và đường dẫn thành phẩm; manifest.json lưu GUID, kích thước, alpha và SHA-256. Không dùng script sửa nội dung ảnh.

Thứ tự thư viện: đá không gian / mìn / máy phát khiên / đèn cứu hộ / lõi điều khiển / vận tải dân sự / móc kéo. Unity nhập full rect, tối đa1024px, không nén, pivot giữa, không bật read/write. Các vòng/cáp/ánh sáng tiếp tục do game vẽ để phản ánh tiến độ và trạng thái.

Ảnh finished-mission-props.png được chụp trực tiếp từ player sau kiểm tra.
